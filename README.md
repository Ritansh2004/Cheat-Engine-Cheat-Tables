## 🛠️ About This Repository

<p align="justify">
This repository contains <strong>Cheat Engine Cheat Tables (`.CT`)</strong> for selected PC games. The tables bring related memory entries, pointer paths, and scripted features together in an organized interface to make supported offline gameplay modifications easier to manage.

## 💻 How to Use the Tables

Follow these steps to use a Cheat Engine table:

### 1. Install Cheat Engine

Download and install [Cheat Engine](https://cheatengine.org/) on your PC.

### 2. Download the Tables

1. Open the [Cheat Tables folder](https://github.com/Ritansh2004/Cheat-Engine-Cheat-Tables/tree/Table%27s).
2. Click the green **Code** button and select **Download ZIP**.
3. Extract the downloaded ZIP file to a folder on your PC.

### 3. Load and Use a Table

1. Launch the supported game. Use these tables in offline gameplay only.
2. Open the corresponding `.CT` file from the extracted folder.
3. In Cheat Engine, attach to the game's running process.
4. Enable the required entries using the table's checkboxes.

## 🤝 Contributing & Guidelines

Contributions that improve existing tables, fix issues, or add useful game-specific features are welcome!

1. Fork this repository.
2. Create a feature branch:


3. Make and test your changes.
4. Commit your changes and open a **Pull Request**.

Please keep contributions organized, clearly named, and relevant to the Cheat Tables in this repository.
